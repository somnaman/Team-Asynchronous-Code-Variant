# Project Graveyard 🪦⚡

> **"EVERYTHING UNFINISHED IS STILL USEFUL."**  
> *A quiet inventory of the ideas waiting for their second life.*

Built by **Team Asynchronous** (Naman Som & Vanshika Sharma) for **CODE VARIANT — BUILD 01 (Round 2)**.

## 🚀 Key Features
- **Drag-and-Drop Action Engine**: Zero standard action buttons; drag cards directly into Action Zones.
- **Interactive Diagnostics Chamber**: Filter friction tags (`#CollegeExams`, `#TechStackLimit`, `#ComplexBug`) and review audit checklists.
- **AI Revival Engine**: 5 distinct pathways (Restart, Continue, Change Idea, Repurpose, Archive).
- **Graveyard Adoption Bazaar**: Community board for taking over stagnant repositories.

## 🛠️ Tech Stack
- **Framework**: React / Next.js / Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Persistence**: LocalStorage API
